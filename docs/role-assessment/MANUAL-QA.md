# Талентийн үнэлгээ — гараар шалгах (бодит бичилт)

Энэ даалгаварт автоматаар шалгах боломжгүй байсан алхмууд. Бүгд staging backend руу **бодит** хүсэлт илгээнэ.
Үр дүнг (HTTP status, `ProblemDetail.code`, `detail`) тэмдэглээд шаардлагатай бол `lib/api-errors.ts`-ийн `ERROR_MESSAGES`-д нэмнэ.

## Бэлтгэл
- Тест үнэлгээ: `9547a97a-342d-4db2-9b40-8e9ef400aee5` ("hunii nuuts") одоо `CREATED`, тестгүй. Урихын өмнө wizard-аар тест сонгож нийтлэх хэрэгтэй (эсвэл аль хэдийн `PUBLISHED` болсон `28696adf-4b2b-42e1-80ee-048ae23ed170`-г тест үнэлгээ болгох эсэхээ шийднэ).
- TEST_EMAIL: өөрийн удирддаг хаяг (`+alias` болно).

## 1. PUBLISHING → PUBLISHED (асинхрон)
1. Тест үнэлгээг нийтэлнэ (wizard → Баталгаажуулах → Нийтлэх).
2. Шууд `/role-assessment/{id}/dashboard` нээнэ.
3. Хүлээгдэх: badge "Нийтэлж байна", "Талент урих" ба "Талент үнэлгээ хаах" идэвхтэй; Network-д `GET /customer/recruitments/{id}` 5с тутам; статус солигдмогц badge "Идэвхтэй" болж polling зогсоно. Шилжилтэд хэдэн секунд зарцуулсныг тэмдэглэнэ.
4. Нийтлэлт амжилтгүй бол (`SUSPENDED`): badge "Саатсан" + tooltip, "Талент урих" идэвхгүй, "Хаах" идэвхтэй.

## 2. Талент урих (зөвхөн TEST_EMAIL, нэг удаа)
1. Dashboard → "+ Талент урих". Имэйл = TEST_EMAIL → талбараас гарахад `POST /customer/hiring-invitations/search-by-email` 200 (өмнө бүртгэлгүй бол нэр хоосон үлдэнэ).
2. Овог/нэр (кирилл, 2–20), утас (заавал биш), дуусах огноо → "Урилга илгээх".
3. Хүлээгдэх: `POST /customer/hiring-invitations/invite` 200, "Урилга амжилтай илгээгдлээ" toast, "Уригдсан талентууд" хүснэгтэд шинэ мөр, төлөв "Уригдсан", Илгээсэн огноо/Урьсан бөглөгдсөн. Товчийг давхар дарахад хоёр дахь хүсэлт явахгүй.
4. TEST_EMAIL-д имэйл ирсэн эсэх.

## 3. Алдааны code (ажиглаж бичих)
- Ижил TEST_EMAIL-ийг дахин урих (давхар урилга): toast-ын текст, `code`, `detail`. **Нэг л удаа**, дахин бүү давт.
- Багтаамж дууссан (`invitationBalance` 0 болсон account): code, detail.
- `CLOSED` үнэлгээнд урих: UI-д товч харагдахгүй; зөвхөн API түвшинд шалгах шаардлагатай бол backend багтай зөвшилцөнө.
- Хүлээгдэх: мэдэгдэхгүй code бүхий 4xx алдаанд серверийн `detail` toast-д гарна.

## 4. Урилгын үйлдлүүд (тест урилга дээр)
- **Сунгах:** урилгын хугацаа дуусмагц (`EXPIRED`, "Хугацаа дууссан") "Дахин урих" → шинэ огноо → `POST …/{invitationId}/extend` 200, төлөв шинэчлэгдэнэ.
- **Үр дүн:** TEST_EMAIL-ээр үнэлгээг бөглөсний дараа "Үр дүн" → `/…/dashboard/{invitationId}`: тест, нэмэлт асуулт, явцын хяналт, "Дэлгэрэнгүй" (HTML тайлан `sandbox=""` iframe), "Тайлан татах" (PDF, нэр нь `Content-Disposition`-оос).
- **Од:** 1–5 од → `POST …/rate` 200, дундаж шинэчлэгдэнэ.
- **Тэмдэглэл:** ≤500 тэмдэгт → `POST …/notes/add` 200, жагсаалтад нэмэгдэнэ.
- **Bookmark:** `/invited-talents`-д тест талентыг тэмдэглэх → `POST …/talents/bookmark` 200, дахин дарж буцаана.

## 5. Хаах (бодит)
- Устгах боломжтой нэг түр үнэлгээг нийтэлж (эсвэл ашиглагдахгүй `PUBLISHED` үнэлгээ дээр) "Талент үнэлгээ хаах" → confirm → `POST /customer/recruitments/close` 200, badge "Хаагдсан", товчнууд алга болно. `CREATED` үнэлгээг серверээр хаах боломжтой эсэхийг (UI-д идэвхгүй) backend-ээс лавлах.
